# Konnections IMAG — Website

Marketing site for [Konnections IMAG](https://www.konnectionsimag.com), a strategic
communications and public relations consultancy. Built with Next.js (App Router) and
deployed to Cloudflare Workers via OpenNext.

## Stack

| Concern | Choice |
| --- | --- |
| Framework | Next.js 15 (App Router, React 19, TypeScript) |
| Styling | Tailwind CSS v4 — theme tokens declared in [globals.css](src/app/globals.css) |
| Motion | Framer Motion for reveals, [Lenis](https://lenis.darkroom.engineering/) for smooth scroll |
| Icons | `lucide-react` |
| Type | Fraunces (display) + Inter (sans), loaded via `next/font` |
| Email | Nodemailer over Gmail SMTP |
| Hosting | Cloudflare Workers via `@opennextjs/cloudflare` |

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000 (Turbopack)
```

### Environment variables

Create `.env.local` in the project root. `.env*` is gitignored — never commit it.

| Variable | Required | Purpose |
| --- | --- | --- |
| `MAIL_USER` | yes | Gmail account used as the SMTP sender for contact-form mail |
| `MAIL_PASS` | yes | Gmail **app password** (not the account password) |
| `ADMIN_EMAIL` | no | Inbox that receives contact submissions. Defaults to `MAIL_USER` |
| `BASE_URL` | no | Absolute URL used in confirmation-email links. Defaults to `https://konnectionsimag.com` |
| `MONGODB_URI` | no | Only read by the currently unused [db.ts](src/lib/db.ts) helper |

/services/public-relations
/services/crisis-management

The homepage is one scrolling document; the navbar links to in-page anchors and the
service pages link back to them.

## Editing content

Copy lives in `src/app/components/text/` so pages stay presentational:

- **[Services.ts](src/app/components/text/Services.ts)** — the six practice areas and
  their bullet lists shown in the homepage `#services` grid.
- **[servicePages.ts](src/app/components/text/servicePages.ts)** — full content for each
  `/services/*` page: kicker, title, intro, hero image, capabilities, and process steps.
  A slug's page is `<ServicePage content={getServicePage('<slug>')} />`, so adding a
  practice area means adding an entry here plus a `page.tsx` and `layout.tsx` under
  [src/app/services/](src/app/services/) and a line in [sitemap.ts](src/app/sitemap.ts).
- **[awards.ts](src/app/components/text/awards.ts)** — awards feeding the carousel,
  ordered newest to oldest. Drop the image in `public/awards-v2/` and add an entry; the
  carousel picks it up with no layout changes.

## Design system

The look is editorial rather than SaaS: white-dominant, hairline rules, serif display
type, and restrained motion. Colours come from the brand mark — teal `#348992`, steel
blue `#2d6389`, rose `#d73c77` — and are exposed as Tailwind theme tokens in
[globals.css](src/app/globals.css) (`text-ink`, `bg-mist`, `text-teal-deep`, …). Use
those tokens rather than raw hex values, and prefer the existing `.eyebrow`,
`.btn-primary`, `.btn-outline`, and `.link-quiet` component classes.

Reveal animations are wrapped in the [ui/](src/app/components/ui/) primitives so that
`prefers-reduced-motion` is honoured in one place.

## Contact form

`POST /api/contact` accepts `{ name, email, phone?, subject, message, requestCaseStudies? }`.
`name`, `email`, `subject`, and `message` are required; anything else returns 400. On
success it sends two mails through [mail.ts](src/lib/mail.ts) — a notification to
`ADMIN_EMAIL` and a confirmation to the sender, which mentions case studies when
`requestCaseStudies` is set.

## Deployment

Cloudflare Workers, worker name `konnectionsimag`, `nodejs_compat` enabled.

```bash
npm run preview   # verify the Worker bundle locally first
npm run deploy
```

Runtime secrets are **not** read from `.env.local` in production — set them on the
Worker (`npx wrangler secret put MAIL_USER`, and likewise for `MAIL_PASS` /
`ADMIN_EMAIL` / `BASE_URL`).

## Known gaps

- [layout.tsx](src/app/layout.tsx) still ships the placeholder
  `google-site-verification` value `your-google-site-verification-code`.
- [sitemap.ts](src/app/sitemap.ts) lists `/services` and `/contact`, neither of which
  exists as a route today (`/services` has a layout but no page; contact is the `#contact`
  anchor).
- [lib/schema.ts](src/app/lib/schema.ts) uses `konnections.co.in` while the rest of the
  site uses `www.konnectionsimag.com`, and nothing imports it yet.
- [lib/db.ts](src/lib/db.ts) and the `mongoose` dependency are unused since the admin
  route was retired.
