# Konnections IMAG — Website

Marketing site for [Konnections IMAG](https://www.konnectionsimag.com), a strategic
communications and public relations consultancy. Built with Next.js (App Router) and
deployed to Cloudflare Workers via OpenNext.

## Stack

| Concern | Choice |
| --- | --- |
| Framework | Next.js 15 (App Router, React 19, TypeScript) |
| Styling | Tailwind CSS v4 — theme tokens declared in [globals.css](src/app/globals.css) |
| Motion | Framer Motion for reveals, [Lenis](https://lenis.darkroom.engineering/) for smooth scroll |
| Icons | `lucide-react` |
| Type | Fraunces (display) + Inter (sans), loaded via `next/font` |
| Email | Nodemailer over Gmail SMTP |
| Hosting | Cloudflare Workers via `@opennextjs/cloudflare` |

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000 (Turbopack)
```

### Environment variables

Create `.env.local` in the project root. `.env*` is gitignored — never commit it.

| Variable | Required | Purpose |
| --- | --- | --- |
| `MAIL_USER` | yes | Gmail account used as the SMTP sender for contact-form mail |
| `MAIL_PASS` | yes | Gmail **app password** (not the account password) |
| `ADMIN_EMAIL` | no | Inbox that receives contact submissions. Defaults to `MAIL_USER` |
| `BASE_URL` | no | Absolute URL used in confirmation-email links. Defaults to `https://www.konnectionsimag.com` |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | no | Cloudflare Turnstile site key. Read at **build** time |
| `TURNSTILE_SECRET_KEY` | no | Turnstile secret. Set both keys or neither |

See [.env.example](.env.example).

## Editing content

Company name, address, phone, email, social links and industries live in one place,
[site.ts](src/app/lib/site.ts). Change them there only. (`public/llms.txt` is plain
text, so update it by hand.)

Copy lives in `src/app/components/text/` so pages stay presentational:

- **[servicePages.ts](src/app/components/text/servicePages.ts)** — everything for each
  `/services/*` page: SEO title and description, intro, overview, capabilities, process
  and FAQs. The homepage practice list shows each page's first four capabilities.
  Adding a practice area means an entry here, a `page.tsx` under
  [src/app/services/](src/app/services/) and a link in `site.ts`. The sitemap picks it up.
- **[faqs.ts](src/app/components/text/faqs.ts)** — homepage FAQ.
- **[awards.ts](src/app/components/text/awards.ts)** — awards feeding the carousel,
  ordered newest to oldest. Drop the image in `public/awards-v2/` and add an entry; the
  carousel picks it up with no layout changes.

When page content changes, bump its date in [sitemap.ts](src/app/sitemap.ts).

## Design system

The look is editorial rather than SaaS: white-dominant, hairline rules, serif display
type, and restrained motion. Colours come from the brand mark — teal `#348992`, steel
blue `#2d6389`, rose `#d73c77` — and are exposed as Tailwind theme tokens in
[globals.css](src/app/globals.css) (`text-ink`, `bg-mist`, `text-teal-deep`, …). Use
those tokens rather than raw hex values, and prefer the existing `.eyebrow`,
`.btn-primary`, `.btn-outline`, and `.link-quiet` component classes.

Reveal animations are wrapped in the [ui/](src/app/components/ui/) primitives so that
`prefers-reduced-motion` is honoured in one place.

## Contact form

`POST /api/contact` accepts JSON `{ name, email, phone?, subject, message, requestCaseStudies? }`.
`name`, `email`, `subject`, and `message` are required. Input is length-limited and
escaped, a hidden honeypot field filters simple bots, submissions are limited to five a
minute per IP (the `ratelimits` binding in [wrangler.jsonc](wrangler.jsonc)), and
Turnstile is enforced when its keys are set. On success it mails the team
(`ADMIN_EMAIL`) and sends the submitter a confirmation that deliberately contains none
of the text they typed.

## Deployment

Cloudflare Workers, worker name `konnectionsimag`, `nodejs_compat` enabled.

```bash
npm run preview   # verify the Worker bundle locally first
npm run deploy
```

Runtime secrets are **not** read from `.env.local` in production — set them on the
Worker (`npx wrangler secret put MAIL_USER`, and likewise for `MAIL_PASS` /
`ADMIN_EMAIL` / `BASE_URL` / `TURNSTILE_SECRET_KEY`).

[next.config.ts](next.config.ts) redirects HTTP and the bare domain to
`https://www.konnectionsimag.com` and sends HSTS and a Content-Security-Policy. If you
add a third-party script, font, image host or embed, add it to the policy. Also turn on
**Always Use HTTPS** in Cloudflare, which covers static files too. Purge the Cloudflare
cache after deploying, because HTML is cached at the edge.
